Privacy Policy

Effective date: 28 November 2026

The short version

XLTab processes spreadsheet files locally on your device. It collects no personal data, transmits nothing, contains no analytics or telemetry, requires no account, and makes no network connections.

What XLTab does

XLTab is a spreadsheet workspace. It reads and writes spreadsheet files that you explicitly open or save. When you use workspace search, it scans only the root folder or spreadsheet file you explicitly choose, and only when you start the search.

What XLTab does not do

  • No collection of personal information or usage data
  • No analytics, telemetry, crash reporting or diagnostic upload
  • No accounts, sign-in, or registration
  • No network requests of any kind — the app works fully offline
  • No advertising, tracking, or third-party analytics SDKs
  • No background indexing or scanning of your drive
  • No access to files or folders beyond the ones you explicitly open or select for a workspace/search

File access

The app opens only the files and folders you choose through the open dialog, drag-and-drop, file associations, folder workspace selection, or workspace-search root selection. Workspace search is an on-demand local scan; it is not a background indexer and results are not uploaded anywhere.

Data storage

XLTab stores no spreadsheet content outside the files you save yourself. Workspace-search caching is in-memory, local to the running app, and keyed to file path, size, and modification time so unchanged files can be refined faster. There is no cloud sync — your spreadsheets remain exactly where you keep them.

Changes

If this policy ever changes, the change will be published on this page before the corresponding app update ships.
